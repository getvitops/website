# /software-hr: SEO analysis

Status: proposal for review. Nothing here is applied to `seed/seed.json`.
Data: Semrush, Canada database, pulled 2026-11-27. See `17-software-pages-overview.md` first.

## Role and verdict

Software category page. **Geo tier B.** HR software is one of the most valuable clicks in the
cluster ($74 for `hr software small business`, $41 for `hr software canada`), and the existing
page has a clear, unusual angle: the HR system is where every other account starts, so it
drives IT setup. That angle also connects this page to `/joining-and-leaving`.

## Current state

- Title: `HR systems | Vitops`. H1: "One employee record that sets up everything else." (good).
- Names Zoho People, Rippling, Collage and Rise; covers HR records and time off, shifts,
  hiring, offer letters and policies, and payroll.

## Recommended changes, highest impact first

1. **Title and meta (high).**
   - Title (49): `HR Software for Small Business in Canada | Vitops`
   - Meta (148): `Zoho People, Rippling, Collage or Rise, set up so a start date or last day adds or removes every account and licence. For Canadian small businesses.`
2. **Use "HR software" in the page, not only "HR system".** The page says "HR systems"; the
   searches say "HR software".
3. **Add a "which fits" table (high).** Four rows. Include a column for Canadian payroll and
   provincial rules, since that is a deciding factor for Ontario businesses.
4. **Lean on the onboarding angle (medium).** One section titled "Employee onboarding software
   that sets up every account" links to `/joining-and-leaving` and answers `employee
   onboarding software`.
5. **State the neutrality (medium).** Say the client owns the accounts, and add a referral disclosure for any tool Vitops is paid on (see `27-referral-disclosure.md`).
6. **Link across (medium).** To `/joining-and-leaving`, `/software-bookkeeping-payroll`.
7. **Structured data (low).** `Service` plus `BreadcrumbList`.
