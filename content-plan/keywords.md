# Keywords — site-wide source of truth

The 23 root `PLAN-*.md` files each carry a `primary_keywords:` block, but there was no
global list and no committed record of what's tracked in Semrush Position Tracking. This
file is that record. `content-plan/tracking/{ottawa,canada}.txt` are generated from the
lists below (paste-ready for Semrush's UI — see `tracking/SETUP.md`).

Volumes are CA-database `phrase_these` pulls, measured 2026-09-07, except where a PLAN
file's own figure is quoted (marked ★).

## Global (tracked in every location)

Brand + the two pillars, per standing decision:

```
vitops · vitops ca · vitops ottawa · vitops ontario
managed it services (4400 ★) · digital marketing (12100 ★)
```

`vitops` itself returns no volume row in `ca` — below Semrush's reporting floor, normal
for a young brand. Tracked anyway: it's how a brand-SERP problem (someone else outranking
us for our own name) gets caught before it costs anything.

## Excluded, with reasons (do not re-add without revisiting the source)

- **Navigational brand traps** — large volume, wrong (product/login) intent:
  `payworks` (165,000/mo), `jobber` (33,100), `zoho books` (6,600), `zoho invoice` (4,400).
- **Below reporting floor / zero volume**: `it support for contractors`, `real estate
marketing ontario`, `trades business software`, `clinic software ontario`, `phipa
compliant it`, `accounting firm it support`, `invoicing software setup`, `slack setup
business`, `crm setup small business`, `microsoft teams setup` (20, KD 0/70).
- **Out of current scope**: `business phone system` (320/mo) — communication-software page
  states VoIP provisioning is not offered. Add the day that scope call changes.
- **Parked on the DoyoBooks positioning gate**: `bookkeeping services` (2400/mo),
  `bookkeeping services ottawa` (320/mo). Largest recoverable pair found in this whole
  pass — see `PLAN-mit-bookkeeping-payroll-software.md` for the SERP-shape analysis. Add
  both the moment that gate opens.

## Semrush plan limit

The current Semrush plan caps Position Tracking at 1 target (domain+location+device
combo), not 1/10 as originally assumed. So the Ottawa/Canada split above is tracked as a
single merged target for now — `tracking/single-target.txt` (84 unique keywords, global +
Ottawa + Canada deduped) — from the Ottawa location. National terms read slightly
local-skewed as a result, but relative movement is still a valid signal. `ottawa.txt` and
`canada.txt` stay as the two-target design to restore if the plan is ever upgraded to
Pro+. See `tracking/SETUP.md` for both paths.
